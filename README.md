Herramientas utilizadas: SQL Server

<p>
•	Problema de Negocio: Una empresa de servicios necesita gestionar el estado de pago de sus clientes, pero no cuenta con un sistema que le permita identificar a tiempo qué clientes están acumulando deuda antes de llegar al corte del servicio. Actualmente no tienen visibilidad clara sobre qué servicios generan más morosidad, qué clientes representan mayor riesgo de impago, ni qué tan efectiva es su gestión de cobranza mes a mes. Esto genera pérdidas económicas y decisiones de cobranza poco informadas.
</p>
<p>
•	Cómo Planeo Resolver el Problema: Para ayudar a esta empresa a identificar patrones de morosidad y tomar mejores decisiones de cobranza, utilizaré SQL Server para modelar la base de datos, extraer información relevante y construir consultas analíticas de complejidad progresiva. Aprovechando funciones de SQL, podré descubrir métricas clave como el nivel de riesgo por cliente, la efectividad de cobro por servicio, y la evolución de la deuda mes a mes. Una vez que la lógica de análisis esté validada en SQL, planeo conectar los resultados a Power BI para construir un dashboard interactivo que le permita al equipo de cobranzas visualizar de forma dinámica qué clientes priorizar y qué servicios requieren mayor atención.
</p>
